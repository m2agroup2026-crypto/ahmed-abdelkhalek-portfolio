# Ahmed Abdelkhalek Portfolio

Production bilingual portfolio for Ahmed Abdelkhalek Sayed — Enterprise Systems & Platform Architect, Full-Stack Developer, and Automation & AI Solutions Architect.

## Public routes

- Arabic homepage: `/`
- English homepage: `/en`
- Arabic insights: `/insights`
- English insights: `/en/insights`

## Features

- Complete English and Arabic interfaces
- Cairo typography and true RTL layout
- Responsive mobile-first design
- Light and dark modes
- Route-based language switching with clean public URLs
- Premium enterprise system cards
- Social links and professional portrait

## Run locally

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and provide `GEMINI_API_KEY` to activate Ahmed Intelligence. The key is read only by the server route and is never sent to the browser.
